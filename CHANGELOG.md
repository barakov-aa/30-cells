# История версий

Формат: номер версии — `ОСНОВНАЯ.ДОПОЛНИТЕЛЬНАЯ.ИСПРАВЛЕНИЕ`.
Новая функция увеличивает среднюю цифру (1.0.0 → 1.1.0), исправление ошибки — последнюю (1.1.0 → 1.1.1),
большие несовместимые изменения — первую (1.1.1 → 2.0.0). Номер текущей версии хранится в `package.json`.

## 1.3.1 — 2026-10-03

Надёжнее хранение резервных копий.

- Сервер игры может только добавлять копии на сервер для копий — прочитать или удалить их оттуда нельзя.
- Подробная инструкция по настройке, проверке и восстановлению из копий.

## 1.3.0 — 2026-10-03

Резервные копии: игры, карточки и настройки больше не потеряются.

- Каждый день сохраняется архив с играми, карточками, усложнениями и настройками сайта.
- Архив автоматически копируется на другой сервер; если копирование не удалось, архив уйдёт со следующим.
- Перед каждым обновлением сайта тоже делается резервная копия.

## 1.2.2 — 2026-10-02

Браузер запоминает вход администратора.

- После входа браузер предлагает сохранить логин и пароль, а в следующий раз подставляет их сам.

## 1.2.1 — 2026-10-02

Удобнее вход администратора.

- Логин администратора можно вводить в любом регистре: «Admin», «ADMIN» и «admin» подходят одинаково. Пароль по-прежнему вводится точно.
- На телефоне поле логина больше не делает первую букву заглавной и не исправляет слово.

## 1.2.0 — 2026-10-02

Счёт команды — это только клетка, на которой стоит её фишка.

- Убраны отдельные очки команд: заработанные баллы сразу переводят фишку вперёд, и больше ничего считать не нужно.
- При правке хода администратор меняет только клетку (и при желании удвоения) — очки отдельно править не надо.
- В таблице команд и на общем экране показана клетка каждой команды.

## 1.1.0 — 2026-10-01

Новое игровое поле — извилистый путь к финишу.

- Клетки идут змейкой от старта к большой клетке финиша «30», как на настольной игре; повороты аккуратно выровнены.
- Клетки «Кино» (10 и 21) по-прежнему выделены отдельным цветом, старт и финиш — своими цветами.
- Фишки, анимация хода, подсветка пути и метки ловушек работают на новом поле.
- Подпись о перемещении фишки показывается в свободном углу поля и не закрывает путь.

## 1.0.0 — 2026-09-30

Первая версия игры.

- Поле из 30 клеток, команды по 2 человека, фишки с автоматическим цветом и анимацией перемещения.
- Кубик: «Да / Нет», «Объяснить словами», «Жестами», «Песни», «Рисование» и «?» — случайное задание со словом про гостей.
- Клетки «Кино» (10 и 21) с карточками из 5 фильмов, сериалов и мультфильмов.
- Фишки «Удвоение» и таймер для каждого задания.
- Скрытые ловушки у каждой команды с усложнениями по категориям; каждая срабатывает один раз.
- Каждая карточка выпадает за игру не больше одного раза.
- Вход администратора, гости по ссылке-приглашению или QR-коду; команды создаёт только администратор.
- Панель администратора: правка клеток, очков, удвоений и ловушек, отмена действий, передача хода.
- Редактор карточек и усложнений с подсказками о повторах слов.
- Общий экран для трансляции: поле, большой таймер, правила до начала игры, холст для рисования.
- Мобильная версия для игроков с компактной шкалой вместо поля.
